# Proposições Lógicas

Uma sentença que pode ser classificada como “Falsa” ou “Verdadeira”.

Não são proposições lógicas as seguintes sentenças:

- interrogativas (ou perguntas);
- exclamativas;
- no imperativo;
- vagas.

## Proposições Simples e Compostas

Uma proposição simples propõe uma única tese, enquanto a proposição composta propõe mais de uma tese.
Atenção aos conectivos lógicos (E, OU, SE...ENTÃO etc.), a proposição será composta.

## Proposições Categóricas

Uma proposição categórica é aquela que diz respeito a uma categoria, não apenas a um único indivíduo.

Elas podem ser classificadas em particulares e universais.

- Proposições universais: quando dizem respeito a todos os elementos de uma categoria. É geralmente caracterizada pela presença de quantificadores, como “todos”, “nenhum”, “nunca”, “sempre”.

- Proposições particulares: quando se referem a apenas alguns dos elementos de uma categoria. É geralmente caracterizada pela presença de quantificadores, como “algum”, “alguns”, “a maioria”, “parte”, “pelo menos um”, “existe um”.

## Proposições Subalternas, Contrárias, Subcontrárias e Contraditórias

**Subalternas**

“Todo Auditor é Engenheiro.”

“Algum Auditor é Engenheiro.”

**Contraditórias**

“Todo Auditor é Engenheiro.”

“Algum Auditor não é Engenheiro.”

**Contrárias**

“Todo Auditor é Engenheiro.”

“Nenhum Auditor é Engenheiro.”

**Subcontrárias**

“Algum Auditor é Engenheiro.”

“Algum Auditor não é Engenheiro.”

## Marcos Temporais

Não são proposições porque elas servem apenas para complementar o sentido da frase a que se refere.
