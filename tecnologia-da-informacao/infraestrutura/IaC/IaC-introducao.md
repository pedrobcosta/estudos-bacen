IaC => Infra as Code

On premisses (modelo tradicional)

- processos manuais
- alto custo
- espaço
- licenças
- tempo
- escalabilidade limitada
- manutenção

Cloud

- IaaS Paas Saas
- automação a infraestrutura
- recursos sob demanda
- escalabilidade
- elasticidade
- baixo custo inicial
- tempo
- alta disponibilidade

Benefícios

- automação
- CI/CD Pipeline (entrega rapida)
- controle de versão
- fácil colaboração
- standards (padronizacao)
- documentacao / auditoria / segurança
