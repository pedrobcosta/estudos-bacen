Aprendizado Supervisionado

Existe um supervisor que detém os resultados esperados. A máquina compara os resultados obtidos com os esperados e aprende com os erros. Classificação.

Aprendizado Não Supervisionado

Não possui rótulos históricos ("resposta correta"). O algoritmo reage conforme a existência ou não de semelhanças entre os dados apresentados, identificando essas semelhanças e agrupando os dados. Clusterização (agrupamento)

Aprendizado por Reforço

Algoritmo descobre por tentativa e erro as ações que geram maiores recompensas. Baseado em feedbacks de interações anteriores. Ex.: Q-Learning

Conceitos adicionais:

- Overfitting: modelo tem resultados excelentes com dados de treino, mas tem performance bem ruim com os dados de teste

- Underfitting: modelo não conseguiu aprender o suficiente sobre os dados, o erro é alto no treino e nos testes.
